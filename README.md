# California House Price Prediction API

A machine learning model that predicts median house prices using the California Housing dataset, deployed as a REST API with FastAPI.

## Overview

This project trains a regression model on the California Housing dataset and serves predictions through a FastAPI web service. You send house and neighborhood details as JSON, and the API returns the predicted house value.

## Features

- Machine learning model trained on the California Housing dataset
- REST API built with FastAPI
- Input validation using Pydantic
- Interactive API documentation (Swagger UI) generated automatically
- Saved model and feature list loaded with joblib

## Tech Stack

- Python 3
- FastAPI
- Uvicorn
- Pydantic
- scikit-learn
- pandas
- joblib

## Dataset

The California Housing dataset (1990 U.S. Census), available through `sklearn.datasets.fetch_california_housing`. Each row describes a census block group in California.

| Feature      | Description                                  |
|--------------|----------------------------------------------|
| MedInc       | Median income in the block group             |
| HouseAge     | Median house age                             |
| AveRooms     | Average number of rooms per household        |
| AveBedrms    | Average number of bedrooms per household     |
| Population   | Block group population                       |
| AveOccup     | Average number of household members          |
| Latitude     | Block group latitude                         |
| Longitude    | Block group longitude                        |

Target: median house value, in units of $100,000.

## Installation

1. Clone the repository:

```
git clone https://github.com/emperorprabin/Simple-Model-deployment-using-FastAPI.git
cd Simple-Model-deployment-using-FastAPI
```

2. Create and activate a virtual environment:

```
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

3. Install the dependencies:

```
pip install -r requirements.txt
```

## Train the Model

The trained model file is not included in this repository because it is too large for GitHub (over 100 MB). Generate it by running:

```
python train.py
```

This creates `house_price_model.joblib` and `house_features.joblib` in the project folder.

## Run the API

Start the server:

```
uvicorn main:app --reload
```

The predicted value is in units of $100,000, so 4.15 means about $415,000.

## Notes

- Input fields are validated with Pydantic. Invalid or missing values return a `422` error with details.
- The model was trained on 1990 census data, so predictions do not reflect current market prices.
